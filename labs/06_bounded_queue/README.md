# L06｜有界队列：等待、关闭与 drain（7h）

材料：R08 CV，R07。这个实验是本月最重要的可手写组件之一。

## 先固定契约
整数队列，capacity>0；0 容量拒绝。
- push(int) -> bool：关闭后拒绝；满且开放时等待。
- pop() -> optional<int>：空且开放时等待；关闭后继续取已入队元素；关闭且空时返回 nullopt。
- close()：幂等；唤醒所有被空/满阻塞的线程。
- 析构前 owner 已经 close 并 join 所有使用者；不在尚有线程访问时销毁队列。

状态不变量：0 <= size <= capacity，closed 一旦置 true 不再恢复。写出两个等待谓词。基线可用 deque<int>，不必先实现环形数组。

## 实现/验证
1. 先单生产者单消费者，容量 1 和 2。
2. 分别测试关闭空队列、关闭满队列、关闭有剩余元素的队列、重复 close。
3. 用 latch/barrier/future 协调测试入口；sleep 可以制造扰动，但不得成为正确性条件。
4. 多生产者使用唯一 ID，检查总数和 multiset 无丢失/无重复；单消费者时还可检查每生产者顺序。
5. 如要证明全局 FIFO，在队列锁保护的线性化位置记录顺序。不能用 pop 返回后另一个无关日志锁的打印顺序推断 FIFO。
6. 反复运行并设置外部超时；压力成功不能代替谓词和线性化点说明。
7. 最后评估锁竞争与慢消费者；暂不改成无锁 MPMC。

## 验收
能完整手写基线；明确 push/pop/close 的线性化位置；被 full/empty 阻塞的线程最终可退出；关闭后残留数据按契约处理。
